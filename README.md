# courtcheck

법원 "나의사건검색" 사이트에서 매번 법원/연도/사건기호/일련번호/당사자명을 손으로 입력하는 번거로움을 줄이기 위한 개인용 사건 진행 확인 대시보드입니다.

**바로 사용하기**: https://digitaltutor26.github.io/courtcheck/ (GitHub Pages로 호스팅되어 있어 별도 다운로드/설치 없이 바로 열립니다)

## 구성

- `index.html` — 사건을 등록/관리하는 대시보드. 데이터는 각 브라우저의 `localStorage`에만 저장됩니다(서버 없음, 사건 데이터는 어디로도 전송되지 않음).
- `courtcheck-autofill.user.js` — [Tampermonkey](https://www.tampermonkey.net/) 등 유저스크립트 매니저용 스크립트(선택 사항, 아래 "자동입력 방식 두 가지" 참고).

이 저장소는 GitHub Pages 및 북마크릿 설치를 위해 **공개(public) 저장소**로 운영됩니다. 커밋되는 파일에는 개인 사건 데이터가 포함되지 않습니다 — 사건 데이터는 각자의 브라우저 `localStorage`에만 저장됩니다.

## 사용 방법

1. https://digitaltutor26.github.io/courtcheck/ 를 브라우저로 엽니다.
2. (최초 1회, 컴퓨터/브라우저마다 한 번씩) 상단 "📋 courtcheck 자동입력" 버튼을 **북마크바로 드래그**해서 북마크로 등록합니다. 북마크바가 안 보이면 `Cmd+Shift+B`(Mac Chrome/Safari)로 표시하세요.
3. 사건을 추가할 때 법원(지원이 있으면 지원까지 선택)/사건번호(연도+기호+일련번호, 예: `2025가단12345`)/당사자명을 입력합니다.
4. 목록에서 "조회하기"를 누르면 나의사건검색 사이트가 새 탭으로 열립니다. 페이지가 다 뜨면 북마크바의 "📋 courtcheck 자동입력"을 **클릭**하세요 — 법원/연도/기호/일련번호/당사자명이 자동으로 채워집니다. 자동입력 방지문자(캡차)만 직접 입력하면 됩니다.
5. 사건번호 형식을 자동으로 인식하지 못한 경우, 값을 복사해 붙여넣을 수 있는 보조 팝업이 대신 뜹니다.
6. 각 사건의 "기록" 버튼을 누르면 감정(감정평가/감정인 절차 등) 진행사항을 자유 기록형 타임라인으로 남길 수 있습니다. 항목마다 "완료"/"예정"을 표시하고 날짜와 메모를 기록하며, 예정 항목이 있으면 "기록" 버튼에 남은 개수가 표시됩니다.

데이터는 브라우저별 `localStorage`에만 저장되므로, 다른 기기/브라우저로 옮기려면 "내보내기/가져오기" 기능을 사용하세요(감정 진행 기록도 함께 내보내기/가져오기됩니다).

## 다른 컴퓨터에서 쓸 때 필요한 준비물

- 별도 설치나 확장 프로그램, 계정, 환경설정이 필요 없습니다. 필요한 건 딱 두 가지뿐입니다.
  1. 위 링크를 열 수 있는 브라우저 (Chrome/Safari/Edge 등 아무거나)
  2. "📋 courtcheck 자동입력" 북마크릿을 그 브라우저의 북마크바에 한 번 드래그해두기
- 사건 목록 자체는 그 컴퓨터/브라우저의 `localStorage`에 저장되므로 자동으로 따라오지 않습니다. 기존 컴퓨터에서 "내보내기"로 JSON을 받아서, 새 컴퓨터에서 "가져오기"로 불러오면 됩니다.

## 자동입력 방식 두 가지

| | 북마크릿 (기본, 권장) | Tampermonkey 유저스크립트 (선택) |
|---|---|---|
| 설치 | 링크를 북마크바에 드래그, 끝 | 브라우저 확장 설치 + Chrome 138+ "사용자 스크립트 허용" 설정 + 스크립트 설치, 브라우저 **프로필별로** 반복 필요 |
| 동작 | 법원 사이트에서 북마크릿을 한 번 클릭해야 채워짐 | 법원 사이트 진입 시 자동으로 채워짐 |
| 이식성 | 어떤 브라우저든 동일 | Tampermonkey를 지원하는 브라우저/프로필에만 |

대부분의 경우 북마크릿이 더 간단합니다. "조회하기" 후 자동으로 채워지길 원하고 Tampermonkey 환경을 이미 갖췄다면 `courtcheck-autofill.user.js`를 계속 써도 됩니다 — 대시보드가 나의사건검색 사이트로 넘길 때 URL에 담는 데이터 형식은 두 방식이 동일합니다.

## 주의사항

이 프로젝트는 개인적인 사건 진행 확인 편의를 위한 도구이며, 법원 사이트의 정식 API가 아닌 화면 자동입력 방식을 사용합니다. 법원 사이트 개편 시 입력창 ID나 법원/지원 목록이 바뀌면 자동입력이 동작하지 않을 수 있습니다.
