# courtcheck

법원 "나의사건검색" 사이트에서 매번 법원/연도/사건기호/일련번호/당사자명을 손으로 입력하는 번거로움을 줄이기 위한 개인용 사건 진행 확인 대시보드입니다.

## 구성

- `index.html` — 사건을 등록/관리하는 대시보드. 브라우저에서 파일을 열기만 하면 동작하며, 데이터는 `localStorage`에 저장됩니다(서버 없음).
- `courtcheck-autofill.user.js` — [Tampermonkey](https://www.tampermonkey.net/) 유저스크립트. 나의사건검색 사이트(`https://ssgo.scourt.go.kr/ssgo/*`)에서 URL 뒤에 담겨온 사건 정보를 읽어 법원/연도/기호/일련번호/당사자명 입력창을 자동으로 채웁니다. 자동입력 방지문자(캡차)는 보안상 채우지 않으며 직접 입력해야 합니다.

## 사용 방법

1. `index.html`을 브라우저로 엽니다(로컬 파일 또는 GitHub Pages 등으로 호스팅).
2. (최초 1회) Tampermonkey 확장을 설치한 뒤, 대시보드 상단 "자동입력 스크립트 설치" 버튼으로 `courtcheck-autofill.user.js`를 등록합니다.
3. 사건을 추가할 때 법원/사건번호(연도+기호+일련번호, 예: `2025가단12345`)/당사자명을 입력합니다.
4. 목록에서 "조회하기"를 누르면 나의사건검색 사이트가 새 탭으로 열리며 입력창이 자동으로 채워집니다. 캡차만 직접 입력하면 됩니다.
5. 사건번호 형식을 자동으로 인식하지 못하거나 스크립트를 설치하지 않은 경우, 값을 복사해 붙여넣을 수 있는 보조 팝업이 대신 뜹니다.

데이터는 브라우저별 `localStorage`에만 저장되므로, 다른 기기/브라우저로 옮기려면 "내보내기/가져오기" 기능을 사용하세요.

## 주의사항

이 프로젝트는 개인적인 사건 진행 확인 편의를 위한 도구이며, 법원 사이트의 정식 API가 아닌 화면 자동입력 방식을 사용합니다. 법원 사이트 개편 시 `courtcheck-autofill.user.js`의 입력창 ID가 바뀌면 자동입력이 동작하지 않을 수 있습니다.
