사건 진행 확인 대시보드

사건을 등록해두고, "조회하기" 클릭 한 번으로 나의사건검색 사이트로 이동 + 법원/연도/기호/일련번호/당사자명이 자동으로 채워집니다. 자동입력 방지문자(캡차)만 직접 입력하면 됩니다. 각 사건의 "기록"에서 감정 진행사항(완료/예정)을 함께 관리할 수 있습니다.
자동입력 설정 (최초 1회만)
1) ① 버튼 → 열리는 페이지에서 "Chrome에 추가"(사용 중인 브라우저용 버튼)를 눌러 Tampermonkey 확장 설치까지 완료 → 2) 설치가 끝난 뒤에 ② 버튼을 누르면 Tampermonkey 자체의 "스크립트 설치" 확인 화면이 뜹니다(Tampermonkey를 먼저 설치하지 않고 ②를 누르면 Chrome의 기본 안내 화면만 뜨니 순서를 지켜주세요) → 3) 사건을 등록하고 "조회하기"를 누르면 자동으로 채워집니다. 스크립트를 설치하지 않아도 복사 도우미 창으로 대체됩니다.
